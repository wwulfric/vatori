# Examples

These apps are developer-facing samples. Keep them small, readable and useful as
starting points for someone building with vatori.

Examples may demonstrate one focused capability, but they should not become
acceptance fixtures. Avoid deterministic test hooks, broad component matrices,
large generated outputs, committed traces or app-specific runtime assertions
here.

Current examples:

- `counter-app`: minimal Flow counter plus desktop title update.
- `grid-app`: small Flow Grid sample.
- `desktop-capabilities-app`: desktop runtime API sample.
- `component-gallery-app`: desktop gallery for major Vaadin components.
